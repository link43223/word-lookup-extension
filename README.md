# 点词即查 / Click to Look Up

一个独立、开源的 Chrome 扩展。阅读英文网页时点击普通文本中的单词，可查看音标、发音和中文释义。释义框始终靠近被点单词显示；电脑浏览器窗口收窄时自动缩小卡片，不切换成底部弹窗。无需注册账号、安装依赖或运行 Aperture、本地服务器及阿里云服务。

An open-source Chrome extension for looking up English words by clicking them on a webpage. It shows pronunciation, phonetics and Chinese definitions in a popover near the selected word. No account, build step or self-hosted server is needed.

一个词第一次查询时需要联网并直接请求有道词典；成功得到的最终卡片数据会原样写入永久个人词库，以后点击同一个词优先从本机读取，不再等待有道。个人词库不设过期时间，也不参加临时缓存清理。若有道给出完整词的释义却没有音标，扩展会从随扩展附带的美音词表按完整拼写离线补查，不会把 `-ed` 或 `-ing` 直接删掉，也不会拿原形音标冒充当前词的音标。此项目与 Aperture 是两个独立项目；本扩展不提供收藏或整句翻译。

连字符词优先查询整词；整词未收录时会分别显示组成词的释义，并明确提示这不等于整词翻译。破折号只作为标点分隔单词，不会把两侧词误认成复合词。未点击时保持原文颜色和网页原有光标，不添加蓝色底纹；点击后，被查的词改为与释义面板标题相同的金色圆角高亮。释义完整返回并写入卡片后才弹出，不逐字播放，也不先弹空卡片；若等待超过约 0.4 秒，会先在单词旁显示独立的简短查询提示，不会提前打开释义卡片。等待期间或卡片出现后，再次点击网页任意位置（包括原单词或别的单词）只会关闭释义并清除高亮；再点一次才查新词。扩展面板使用暖白和深灰；面板根据被点击文字所在区域的底色切换明暗，不跟随电脑系统主题。释义框根据单词位置在邻近留白、上方或下方显示，窄窗口下自动收窄，以短距离淡入出现且不会将整页压暗；内容过长时可在框内滚动，释义不会删减或折叠。圆角标记只画在扩展自己的浮层上，按被点击单词的实际位置摆放；不会包裹或改写原文文字节点，也不影响周围单词的排版。遇到跨行等不适合叠加圆角标记的情况，会退回原有的文字高亮。点击浏览器工具栏中的扩展图标，可查看简短使用提示。

若整词有释义但词典未提供整词音标，会尝试显示明确标注的组成词音标，不把它冒充整词音标。

卡片以被点击的完整词和它本身的释义为主，不在标题旁额外添加“原形”提示；现在分词、过去式等信息只保留词典释义本身的说明，不重复显示。若本地美音词表列出几个不同读音而有道没有音标，卡片会显示这些读音，不擅自选一个。英音仍只取自有道，不能将本地美音误标为英音。本地词表来源和许可见 [`pronunciation/SOURCE.md`](pronunciation/SOURCE.md)。升级到本版后，当前格式的旧成功缓存会原样迁入永久个人词库，不重新联网补字段或改变已有词条。

对于 `Jooste's` 这样的所有格，扩展先查完整形式，再查去掉 `'s` 的原词。若原词也不在词典中，会解释 `'s` 的含义，不把相似拼写的其他名字冒充释义。有道精确收录的人名保留原词条和中文译名，卡片标题使用原文中的大小写。已删除文章人名推测与手写参考译名：不会扫描整篇文章、推测中文名字或替换词典结果。词典未收录和网络失败会分别提示。

释义按 `n.`、`v.`、`adj.` 等词性分行，每行使用面板全宽并自然换行；词典返回的释义全部直接显示，并始终保留原有词性顺序，不根据所在句子重新排序，不折叠、不省略、不合并重复或相近的内容。`vt.`、`vi.`、`npl.` 等原始词性标记会分别显示。保留词典原文里的分号，不把分号之间的片段猜成独立义项。未知格式仍作为普通文字保留。

这属于轻量阅读辅助而非完整的语言学消歧：词典接口没有提供可靠的逐义项频率/例句标签，因而不能保证每个词都能准确选出句中义。无法判断时会保留词典次序和全部义项，不会编造或静默删掉内容。

点击发音按钮后播放有道美音，喇叭在播放期间变绿；播放结束恢复原色。音频失败则短暂变红并提示播放失败，不再自动切换到系统机械朗读。音频不保存在个人词库中，需联网播放。点击释义文字不会关闭卡片，可选中复制；关闭按钮、Esc 或点击网页外侧仍可关闭。

## 下载与安装

1. 在本仓库页面点击 **Code → Download ZIP**，下载后解压。也可以用 Git 克隆仓库。
2. 在 Chrome 地址栏输入 `chrome://extensions`，打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择**直接包含 `manifest.json` 的文件夹**（不是 ZIP 文件，也不是它的上一级文件夹）。
4. 刷新已经打开的英文网页，点击普通文本中的英语单词即可查词。

当前提供的是源码安装方式，**没有发布到 Chrome 网上应用店**。更新时下载新版文件，在 `chrome://extensions` 点击此扩展卡片的刷新按钮，再刷新正在阅读的网页。Chrome 不允许网页代替用户完成首次加载。

## 权限与数据

扩展会在 HTTP/HTTPS 网页加载识别点击单词的脚本。鼠标经过正文只唤醒本地后台，不访问有道、不预查单词；点击后仅发送被查询的单词，不发送整句或文章。查询结果保存在扩展自己的持久存储中，不是浏览器网页缓存。扩展不连接作者的服务器。

查询依赖第三方词典服务；服务不可用或返回格式发生变化时，释义可能无法加载。此仓库不包含有道词典的数据，也不代表有道官方产品。

完整释义准备好后立即返回卡片，不等待本地写入、备份或磁盘维护。相同的完整数据对象会先进入内存供重复点击复用，再由后台写入稳定的 `library:v1` 个人词库。包括单词、音标、原始释义行、显示义项和提示字段，保留未知扩展字段；不对词库中的成功数据设置过期时间。存储失败不会阻止卡片显示：扩展图标和词库管理页会提示，后台保留数据并重试；词条数量只统计永久保存成功的内容。待写入数据另存于浏览器会话存储，后台休眠或重启后可继续保存，但会话存储不跨浏览器完全退出。若尚未写入永久词库就强制退出浏览器或断电，最新词条仍可能未保存，不能承诺零丢失窗口。个人词库使用 `storage`、`unlimitedStorage`；`alarms` 用于后台休眠后的备份重试。明确未收录的词只短暂缓存，网络失败不缓存。

本地返回的是**当时成功查询并保存的完整卡片数据快照**，不是整个有道网页，也不会偷偷同步成后来变更的在线释义。有道未提供音标时的离线补充、组成词和所有格回退均沿用上述规则；不会把这些补充伪称为有道原始返回。词性只合并连续的同类行，不把分散出现的同词性义项调换顺序。

### 自动备份与恢复

点击扩展图标 → **词库与备份**，在独立页面管理文件；工具栏小窗口关闭不再打断文件选择。

1. **选择自动备份文件**：选择电脑上的 JSON 文件。若文件已有内容，先验证并合并其中缺少的词条，再写入当前完整词库；无效文件不会被覆盖。
2. **确认状态**：页面显示本地词条数、备份文件名、上次成功时间，以及等待备份、需要授权或失败原因。只有文件写入并关闭成功，才显示备份成功。
3. **自动更新**：新增词条后约 1.2 秒合并触发一次备份。后台休眠时由浏览器闹钟继续检查；写入失败保留待备份状态并定期重试。浏览器关闭时无法写文件，启动后再继续，因此卸载前务必确认最近一次备份成功。
4. **重新授权**：浏览器要求文件权限时，在管理页点“重新授权”。安全限制下不能保证授权永久有效。
5. **恢复备份**：验证整个文件后，只补充本地缺少的词条，不覆盖已有词条。恢复会清除网页内存中的旧副本，迟到的网络回答不能覆盖恢复的数据。单次导入最大 32 MB、10 万词条，超限会拒绝且保留原文件，不做部分导入。
6. **下载独立副本**：额外下载一个带日期的完整 JSON 快照；请到浏览器下载记录确认完成。这不是自动更新文件。

关闭、重开浏览器，或更新同一扩展 ID 的代码，不会清空个人词库。换浏览器用户、换扩展 ID、清除扩展数据或卸载扩展会失去内部词库；电脑上已经成功保存的独立备份文件不受影响。重新安装后需要选择文件恢复，并重新连接自动备份，不能绕过浏览器权限自动搜索电脑文件。修改源码目录后请重新加载**原扩展**，不要先卸载。

## 开发

无需构建步骤。安装 Node.js 后可在此目录运行 `node --test *.test.js` 检查查词和显示逻辑。修改文件后在 `chrome://extensions` 重新加载扩展，并刷新测试网页。

## 项目结构

- `manifest.json`：Chrome 扩展配置及权限。
- `popup.html`：浏览器工具栏中的简短使用提示。
- `popup.js`：词库数量、备份摘要与管理页入口。
- `library.html` / `library-page.js` / `library-ui.js`：独立词库管理页、文件授权、备份与恢复。
- `content.js`：查词交互、临时高亮和靠近单词的释义卡片。
- `service-worker.js`：直接向有道词典查询释义，并永久保存成功结果。
- `pronunciation/en_US/`：离线美音音标词表，仅在有道没有整词音标时按首字母读取。
- `icon.svg` / `icon.png`：扩展自己的图标。
- `lookup.test.js` / `meaning-render.test.js` / `library.test.js`：查词、显示、持久存储与备份恢复的回归测试。
